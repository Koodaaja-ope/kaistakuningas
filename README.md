# Kaistakuningas

Yhden tiedoston 2D-ajopeli selaimeen. Avaa `index.html` selaimessa aloittaaksesi.

## Ohjaus

- Ohjaa vasemmalle ja oikealle nuolinäppäimillä tai A/D-näppäimillä.
- Kiihdytä ylösnuolella tai W:llä ja jarruta alasnuolella tai S:llä.
- Kosketusnäytöllä käytä pelin alla näkyviä painikkeita.

Peli ei tarvitse asennusta tai ulkoisia kirjastoja. Ennätys tallentuu selaimen paikalliseen tallennustilaan.
